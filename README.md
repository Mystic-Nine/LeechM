## ✨ Why Choose Project-X?

> A next-generation Telegram bot designed to make file management completely effortless. Whether it's torrents or cloud storage, everything is just one command away. Built for speed, flexibility, and absolute simplicity. ⚡

### 🌟 Core Features

*   **🌐 Universal Downloader:** Fetch files seamlessly from Torrents, Mega, Google Drive, direct links, and any site supported by `yt-dlp`.
*   **☁️ Cloud Uploader:** Instantly mirror files to Google Drive, Telegram Cloud, Rclone remotes, or DDL servers in seconds.
*   **📦 Smart File Handling:** Automatic renaming, tagging, and organizing of media metadata (titles, languages, etc.).
*   **🧠 Intelligent Automation:** Built-in auto-cleanup, retry, and resume mechanisms to keep your tasks running stably 24/7.
*   **⚙️ Advanced Controls:** Manage operations directly within Telegram using a rich command system (e.g., `/mirror`, `/leech`, `/bs`).
*   **🎯 Multi-Deployment Ready:** Deploy effortlessly anywhere: **Heroku**, **Docker**, **VPS**, or **Google Colab**.
*   **🧩 Modular Core:** Highly customizable and extendable modules requiring minimal Python knowledge.
*   **🔐 Secure & Private:** Includes built-in access controls, user whitelisting, and strict owner-only command filters.
*   **🪶 Lightweight Performance:** Highly optimized async codebase powered by **Pyrogram** and **uvloop** for maximum efficiency.
